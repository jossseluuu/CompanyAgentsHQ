# ADR 0003: licencia propietaria

**Contexto.** La especificación dudaba entre MIT y una licencia restrictiva. El dueño quiere poder comercializar el producto.

**Decisión.** Todos los derechos reservados (`LICENSE`). Sin licencia abierta. El repositorio debe ser privado.

**Consecuencias.** Las dependencias y los recursos deben admitir uso comercial: se registran en `docs/creditos.md`. Conviene revisar el texto con un profesional antes de vender.
